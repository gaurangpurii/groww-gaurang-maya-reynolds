# Dr. Maya Reynolds — Homepage Redesign

Built for the Grow My Therapy Stage 2 internship assignment: a structural recreation of the Conejo Valley Family Counseling homepage, redesigned around Dr. Maya Reynolds' fictional profile.

## Run locally

```bash
npm install
npm run dev
```
 
Open http://localhost:3000 

## Design notes

- Theme: deep sage, warm sand, terracotta, Fraunces + Inter.
- Maya's supplied portrait and the two supplied office photographs are used as profile assets.
- Supporting editorial photography uses Pexels URLs and is credited in `IMAGE-CREDITS.md`.
- The homepage preserves the original template's major rhythm: hero, introduction, who-we-help cards, expertise band, how-we-work, specialties, appointment CTA and footer, while adding the required Our Office section and profile-tailored FAQ.
- The content is based on the supplied Dr. Maya Reynolds profile; no unsupported certifications or experience claims are added.

## Before submission

```bash
npm run build
```

Then push the project to a public GitHub repository and import it into Vercel for the live-site deliverable.
